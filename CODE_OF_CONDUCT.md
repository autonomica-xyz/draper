# Code of Conduct

This project is a professional collaboration space. Contributors are expected to:

- communicate respectfully and constructively,
- focus technical disagreement on evidence and project goals,
- avoid harassment, threats, discriminatory language, and personal attacks,
- protect private information, credentials, and unpublished security reports.

Maintainers may remove comments, issues, pull requests, or participants that violate these
expectations.

Report conduct concerns to `hello@your-domain.example`.
